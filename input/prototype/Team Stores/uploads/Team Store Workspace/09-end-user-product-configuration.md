# End-User Product Configuration

The product-detail surfaces where buyers personalize and size gear. The single PDP and the bundle/uniform-kit configurator share the same page structure, meta-data, and personalization flow — the configurator just repeats that flow per item and per player. Responsive: the same web surfaces render on mobile screens.
