# Fonts

The design system typeface is **Gotham** (Book 400, Medium 500, Bold 700, Black 800).
Gotham is commercially licensed and not included in this package — place your licensed
`Gotham-*.woff2` files here and add the matching `@font-face` rules to `style/_global.scss`.
Until then, pages fall back to the system font stack defined in `$font-stack`.
