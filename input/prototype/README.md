# Prototype

Put the front-end prototype source here (HTML, React or Vue; no database).
Copy the project's source, e.g. `package.json`, `src/`, `public/`, `index.html`.
Leave out `node_modules/` — the prototype-answerer skips it anyway.

Used by `/req-team` (adds an `answerer-<slug>` teammate per file) and
`/prototype-answer` (answers questions in existing run folders).
